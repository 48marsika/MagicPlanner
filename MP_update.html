MagicPlanner · обновление платежей

Текущий месяц — без прокрутки

В «Обязательных платежах» теперь по умолчанию открывается текущий месяц. Видны только его галочки, а другие месяцы доступны стрелками ‹ и ›. Кнопка «Сегодня» возвращает к текущему месяцу. Все прежние данные сохраняются.

1. Сохрани резервную копию

Открой свой MagicPlanner → «Настройки» → «Создать резервную копию». Сохрани файл .json перед обновлением.

2. Подготовь файлы автоматически

Помощник получает актуальную версию из публичного репозитория и вносит только изменения раздела платежей. Другие вкладки не меняются.

Нажми кнопку выше.

Если GitHub не загрузился

Открой GitHub → index.html, нажми Raw, затем Ctrl+S и выбери сохранённый исходный файл ниже. Можно также выбрать существующий service-worker.js (необязательно).

3. Скачай оба файла

Проверь названия перед загрузкой на GitHub: строго index.html и service-worker.js, без (1) или (2).

4. Обнови сайт

  • Открой GitHub → MagicPlanner, выбери ветку main.
  • Нажми Add file → Upload files и выбери два скачанных файла. Подтверди их замену и нажми Commit changes.
  • Открой опубликованный MagicPlanner, обнови Ctrl+F5 и проверь «Казна → Обязательные платежи».

Сам помощник GitHub не изменяет; он создаёт готовые файлы у тебя на компьютере. Доступ к аккаунту не требуется.
